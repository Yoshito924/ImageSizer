# ImageSizer

画像のリサイズ、クロップ、フォーマット変換を行うGUIアプリケーションです。SNSヘッダーやWeb用画像のプリセットを備え、複数の画像をまとめて処理できます。

![ImageSizer メイン画面](images/ImageSizer.gif)

## 主な機能

### 画像処理機能
- **リサイズ**: ファイルサイズ（MB）または画素数（幅/高さ）で指定
- **クロップ**: 正方形、16:9、4:3、9:16、カスタム比率に対応
- **フォーマット変換**: WebP、PNG、元のフォーマット維持
- **バッチ処理**: ドラッグ&ドロップで複数画像を一括処理
- **自動調整**: 目標サイズに応じて自動的に拡大・圧縮

### プリセット機能
便利なプリセットサイズを搭載：
- **SNSヘッダー**: 
  - X (Twitter): 1500x500
  - note: 1280x670
  - YouTube: 2048x1152
- **Web画像**: 
  - メインビジュアル: 1600px幅
  - プロジェクト詳細: 1200px幅
  - サムネイル: 400px幅
- **SNS投稿**: 
  - Instagram正方形: 1080x1080
  - Instagram縦長: 1080x1350
  - Instagramストーリー: 1080x1920

### ファイル名カスタマイズ
出力ファイル名に以下の情報を含めることができます：
- クロップタイプ（クロップ時のみ）
- サイズ比率（サイズ変更時のみ）
- タイムスタンプ（YYYYMMDD_HHMMSS）
- 連番（001, 002, ...）
- プリセット名（プリセット使用時のみ）

### その他の機能
- ウィンドウを常に最前面に表示
- ウィンドウのサイズと位置を記憶
- 設定の自動保存・復元
- 処理進捗のリアルタイム表示

## 対応フォーマット

### PDF・Office文書の画像化

画像と同じ画面からPDF、PowerPoint（.pptx）、Word（.doc / .docx）、
Excel（.xls / .xlsx / .xlsm）を選択・ドロップできます。文書はページ・スライドごとに
画像化し、選択中のクロップ、リサイズ、容量調整、プリセット、出力形式を適用します。
画像と文書を混ぜて一括処理することもできます。

- 例：横幅1200px・WebPを選び、PowerPointをドロップすると全スライドをWebPで保存します。
- 「元のフォーマットを維持」を選んだ文書はPNGで保存します。
- 「サイズ変更なし」や容量指定では、横幅1920pxで画像化してから処理します。
- 出力は `文書名_001.png` などのページ番号付きです。既存の文書出力と同名になる場合は連番を追加します。
- 保存先は既存の「元のフォルダ」「output」設定を使います。一時PNG・PDFは処理後に削除します。
- Office文書の変換にはWindowsと対応するデスクトップ版Microsoft Officeが必要です。PDFにはOfficeは不要です。
- Excelは印刷設定に沿ったページ分割になります。パスワード保護PDFには対応していません。
- 処理中は終了できません。途中でエラーが起きても、保存済みのページは残ります。

追加依存関係も含め、`pip install -r requirements.txt` でインストールしてください。
文書変換処理は `document_processor.py` に分離しています。Pptx2Image本体の配置には依存しません。

ImageSizer は以下の画像フォーマットに対応しています：

- PNG (.png)
- JPEG (.jpg, .jpeg)
- BMP (.bmp)
- TIFF (.tiff)
- WebP (.webp)
- SVG (.svg、PNG/WebPとして出力)

注意：GIF (.gif) ファイルは処理されません。

## 要件

- Python 3.6以上
- 以下のPythonライブラリ:
  - tkinter
  - Pillow (PIL)
  - tkinterdnd2
  - resvg-py

## インストール方法

1. このリポジトリをクローンまたはダウンロードします。（ページ上部、緑色の「<>Code▼」ボタンから選択）
2. お使いのPCに必要なライブラリをインストールします：

   ```bash
   pip install -r requirements.txt
   ```

3. `python main.py` を実行してアプリケーションを起動します。

## プロジェクト構成

- `main.py`: アプリケーションのエントリーポイント
- `image_processor.py`: 画像処理のコア機能
- `gui.py`: ユーザーインターフェース
- `settings.json`: 設定ファイル（自動生成）

## 使用方法

1. アプリケーションを起動します。

2. プリセットを選択するか、カスタム設定を行います：
   - プリセットドロップダウンから適切な設定を選択
   - またはカスタムでクロップ・サイズを設定

   ![ファイル追加](images/add_files.png)

3. 以下のいずれかの方法で画像を追加します：
   - 画像ファイルをウィンドウにドラッグアンドドロップ
   - 「ファイルを選択」ボタンをクリックして画像を選択

4. クロップ設定（カスタムの場合）：
   - クロップなし
   - 正方形（1:1）
   - 16:9
   - 4:3
   - 9:16
   - カスタム比率（縦横比を指定）

   ![クロップ設定](images/crop_settings.png)

5. サイズ設定（カスタムの場合）：
   - 変更なし：サイズ変更を行わない
   - MBで指定：ファイルサイズで指定
   - 横ピクセルで指定：画像の幅で指定
   - 縦ピクセルで指定：画像の高さで指定

   ![ファイル追加](images/size_settings.png)

6. 出力フォーマットを選択：
   - 元のフォーマットを維持
   - WebP形式に変換（高圧縮・高品質）
   - PNG形式に変換

7. ファイル名パターンを設定：
   必要な情報にチェックを入れます

8. 画像をドロップまたは選択すると、処理が自動的に開始されます。

   ![処理結果](images/result_example.png)

## 設定ファイル

アプリケーションの設定は `settings.json` ファイルに自動的に保存され、次回起動時に復元されます。
設定ファイルには以下の項目が含まれます：

- 最前面表示の状態
- クロップタイプ
- サイズ設定
- 出力フォーマット
- ウィンドウサイズと位置

初めて使用する場合は、`settings.json.template` を `settings.json` にコピーしてください：

```bash
cp settings.json.template settings.json
```

## 注意事項

- GIF画像は処理されません
- 処理された画像は元のファイルと同じフォルダに保存されます
- 既存のファイルは上書きされません（連番が付与されます）
- クロップ機能を使用すると、画像の一部が切り取られます
- WebP形式に変換する場合、RGBA画像は自動的にRGBに変換されます
- WebP形式で出力する場合、縦または横が `16383px` を超える画像は上限に合わせて自動縮小されます
